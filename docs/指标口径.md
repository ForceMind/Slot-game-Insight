# SlotInsight 指标口径

本文说明面板使用的资金、局次、Slot 游戏参数、累计下注分层和大用户分析口径。

## 1. 基础事件与局次

### 原始事件

- 下注金额统一转换为正的流水金额。
- 中出金额统一转换为正的派彩金额。
- 经营资金指标按筛选范围内的全部原始事件计算。

### 局次重建

数据没有显式局次编号时，面板按以下规则重建：

1. 同一玩家的一次下注开启一局。
2. 下一次下注前的中出归入当前局。
3. 下一次下注开启下一局。
4. 导出窗口开头、首次下注前的中出无法可靠归属，不参与局次指标。

因此，总派彩等原始事件指标可能与重建局次中的派彩合计存在差异。这是口径差异，不是计算丢失。

## 2. 经营资金指标

| 指标 | 公式或定义 |
| --- | --- |
| 总流水 | 全部下注金额绝对值之和 |
| 总派彩 | 全部中出金额之和 |
| GGR | 总流水 - 总派彩 |
| RTP | 总派彩 / 总流水 × 100% |
| Hold | GGR / 总流水 × 100% = 100% - RTP |

Hold 表示每单位下注中游戏或平台理论保留的比例。例如 RTP 为 97%，Hold 为 3%，表示每下注 100 金币，平台在该观察口径下保留 3 金币。Hold 未扣除获客、渠道、税费、人工等运营成本，因此不是最终利润率。

## 3. Slot 游戏参数

| 参数 | 定义 |
| --- | --- |
| RTP | 局次派彩 / 局次流水 × 100% |
| Hold | 局次 GGR / 局次流水 × 100% |
| 中奖局率 | 派彩大于 0 的局次占比 |
| 空奖局率 | 派彩等于 0 的局次占比 |
| 平均下注 | 单局下注金额平均值 |
| 下注中位数 | 单局下注金额的 50 分位数 |
| 下注变异系数 | 下注标准差 / 平均下注 |
| 净赢分标准差 | 单局玩家净赢分的总体标准差 |
| 返还波动性 | 单局返还倍率的总体标准差 |
| 每局期望 GGR | 总 GGR / 局数 |
| 最大单局赢分 | 玩家单局最大净赢分 |
| 最大单局亏损 | 玩家单局最大净亏损的绝对值 |
| 95 分位返还倍率 | 95% 局次不超过的返还倍率 |
| 10 倍大奖率 | 返还倍率不低于 10 倍的局次占比 |
| 50 倍超级大奖率 | 返还倍率不低于 50 倍的局次占比 |
| 最大连赢 | 单一玩家连续净盈利局次的最大长度 |
| 最大连输 | 单一玩家连续净亏损局次的最大长度 |
| 平均连赢 | 所有连续盈利段的平均长度 |
| 平均连输 | 所有连续亏损段的平均长度 |
| 前 1% 玩家流水占比 | 按流水排序的前 1% 玩家贡献占比，人数向上取整且至少 1 人 |
| 前 1% 玩家派彩占比 | 按派彩排序的前 1% 玩家获得的派彩占比 |
| 玩家盈利比例 | 观察期累计净盈利玩家占比 |
| 人均局数 | 总局数 / 活跃玩家数 |

返还倍率定义为：`单局派彩 / 单局下注`。玩家单局净赢分定义为：`单局派彩 - 单局下注`。

## 4. 累计下注分层

分层按玩家在当前分析范围内的累计下注计算。全游戏总览会跨全部游戏汇总同一个用户，同一玩家只进入一个互斥档位：

- 1 万以下
- 1 万至 10 万
- 10 万至 20 万
- 20 万至 50 万
- 50 万至 100 万
- 100 万至 200 万
- 200 万及以上

饼图分别展示各档位玩家数占比和流水贡献占比。

## 5. 大用户分析

大用户范围提供三个业务筛选条件：

- 累计下注 200 万及以上
- 累计下注 100 万至 200 万
- 累计下注 100 万及以上

其中第一个和第二个范围都会包含在第三个范围中，这是有意保留的业务筛选关系。

| 指标 | 定义 |
| --- | --- |
| 首次游戏 | 该用户最早一笔可重建下注局对应的游戏 |
| 流水偏好游戏 | 该用户累计下注最高的游戏 |
| 局数偏好游戏 | 该用户下注局数最多的游戏 |
| 下注档位偏好 | 该用户出现局数最多的单局下注档位 |
| 活跃天数 | 至少存在一局下注的自然日数量 |
| 玩家净盈亏 | 累计派彩 - 累计下注 |

当两个游戏的偏好值相同时，系统按游戏名稳定排序选择一个结果，保证重复计算一致。

## 6. 时间汇总

- 每小时：按自然小时汇总。
- 每天：按自然日汇总。
- 每周：以周一为每周起始日汇总。

时间曲线支持页面日期范围筛选，并提供图内范围条、框选缩放和滚轮缩放。缩放仅改变可视范围，不改变指标计算结果。
