# SlotInsight

SlotInsight 是一个面向 Slot 游戏运营和数学表现分析的本地数据面板。它直接读取项目 `数据/` 目录中的 Excel 文件，也支持在页面中临时上传文件；原始数据只在本机处理，不会被提交到 Git。

## 主要功能

- 全游戏经营总览：横向比较流水、派彩、GGR、RTP、Hold、活跃玩家和局数。
- 累计下注分层：按互斥档位展示玩家构成和流水贡献饼图。
- 大用户分析：支持累计下注 200 万及以上、100 万至 200 万、100 万及以上三种范围。
- 大用户下钻：分析首次游戏、按流水和局数计算的偏好游戏、下注档位偏好、活跃天数及累计盈亏轨迹。
- 单游戏分析：经营概览、人群分析、局次分析、玩家分析和数据明细。
- Slot 游戏参数：23 项 RTP、波动性、连赢连输、大奖率和玩家集中度等指标，可在全游戏总览中选择多个游戏比较。
- 时间曲线：支持按小时、每天、每周汇总，可使用范围条、框选和滚轮自由缩放。
- 中文图表与表格：页面、图表、悬浮字段和表格筛选菜单均使用中文。
- 大数字显示：自动使用万、亿等单位，避免指标卡溢出。

完整指标定义见 [指标口径](docs/指标口径.md)。

## 启动

### macOS

双击项目根目录中的 `启动面板.command`。首次启动会自动创建 `.venv` 并安装依赖。

如果 macOS 首次阻止执行，可在 Finder 中右键该文件，选择“打开”。

### Windows

双击 `run.bat`。

### Linux 或终端

```bash
./run.sh
```

启动后默认访问：<http://localhost:8501>

要求本机已安装 Python 3。首次安装依赖需要网络连接，之后可直接启动。

## 数据文件

将一个或多个 `.xlsx` 或 `.xlsm` 文件放入项目根目录的 `数据/` 文件夹。每个文件代表一款游戏，面板会从文件名中提取游戏名，例如：

```text
数据/
  Tigerslot游戏用户明细_0811.xlsx
  lava_link游戏用户明细_0811.xlsx
```

必需字段支持以下中文或英文别名：

| 标准字段 | 支持的常用列名 | 说明 |
| --- | --- | --- |
| 用户编号 | `uid`、`user_id`、`用户ID` | 玩家唯一标识 |
| 场景 | `场景`、`scene`、`event`、`type` | 下注或中出事件 |
| 金币数量 | `金币数量`、`amount`、`coin_amount` | 下注可为负数，中出可为正数 |
| 时间 | `时间`、`create_date`、`datetime`、`日期` | 事件发生时间 |
| 地区 | `地区`、`region`、`country` | 可选，缺失时记为“未知” |
| 设备 | `设备`、`device`、`platform` | 可选 |
| 性别 | `性别`、`gender` | 可选 |
| 语言 | `语言`、`language`、`locale` | 可选 |

场景文本包含“下注”或 `bet` 时识别为下注，包含“中出”“中奖”“派彩”、`win` 或 `payout` 时识别为中出。无法从场景判断时，系统会使用金额正负辅助识别。

## 数据安全

`.gitignore` 已忽略以下本地内容：

- `数据/`
- `.venv/`
- Streamlit 缓存和 Python 缓存

提交前可运行以下命令确认 Excel 文件未被 Git 跟踪：

```bash
git check-ignore -v 数据/*.xlsx
git ls-files 数据 .venv
```

第二条命令应无输出。请勿使用强制添加命令将数据文件加入 Git。

## 指标口径摘要

- 一次下注开启一局。
- 下一次下注前，同一玩家的中出归入当前局。
- 导出窗口开头无法归属到下注的中出，不参与局次指标。
- 总流水、总派彩、GGR 和经营 RTP 使用全部原始事件计算。
- 中奖率、波动性、连赢连输和大奖率使用可重建的完整局次计算。
- `Hold = GGR / 总流水 × 100% = 100% - RTP`。Hold 表示游戏留存率，不等于扣除运营成本后的利润率。

## 开发与验证

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m unittest discover -s tests -v
.venv/bin/python -m pip check
git diff --check
```

主要模块：

- `app.py`：Streamlit 页面和交互。
- `data_utils.py`：数据读取、字段规范化和筛选。
- `slot_metrics.py`：局次重建及 Slot 指标计算。
- `table_utils.py`：中文 AG Grid 表格。
